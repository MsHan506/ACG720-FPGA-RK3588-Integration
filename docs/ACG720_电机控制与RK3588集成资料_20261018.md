## 6. RK3588 UART 控制链路

### 6.1 当前整机真实状态

**未完成。** 当前公开仓库的 `b_full_top` 明确采用输出单向链路：FPGA 通过 `sensor_uart_tx` 向 RK3588 发传感器遥测；没有实例化 `ai_uart_command_receiver`，没有 RK3588→FPGA 的 RX 顶层端口，也没有有效管脚约束。

### 6.2 已有但尚未集成的接收器候选

- 文件：`src/ai_uart_command_receiver.v`
- 电气前提：3.3 V TTL、共地
- 串口：115200 baud、8N1
- 帧长：8 字节
- 帧格式：`A5 5A SEQ CMD LEFT RIGHT FLAGS XOR`
- 校验：前 7 字节逐字节 XOR
- `LEFT`、`RIGHT`：有符号 int8，单位 RPM，模块限幅到绝对值 80 RPM
- 命令：`00` 心跳、`01` 使能、`02` 速度、`03` 停止、`04` 紧急停止
- 看门狗：350 ms；使能后超时会清除 active、速度归零并产生 stop pulse
- 普通 STOP：速度归零并产生 stop pulse，但源码中不清除 `active`
- ESTOP：清除 `active`、速度归零并产生 stop pulse
- 当前证据：独立 RTL 仿真通过；未合入整机顶层、未分配管脚、未上板

模块级样例（不是当前整机可直接使用的命令）：

```text
A5 5A 01 01 3C 3C 00 FF   # ARM，左右 60 RPM
A5 5A 02 02 3C 3C 00 FF   # VELOCITY，左右 60 RPM
A5 5A 03 03 00 00 00 FF   # STOP
A5 5A 04 04 00 00 00 FF   # ESTOP
```

在正式集成前，必须先选定一个确实空闲的 3.3 V FPGA 输入、补顶层端口和 CST，并规定本地遥控与 RK3588 控制谁有更高优先级。

## 7. FPGA→RK3588 遥测

公开仓库当前版本使用 V3，115200 8N1、20 Hz、固定 28 字节、CRC-16/CCITT-FALSE。它包含距离、强度、姿态、错误计数和 FPGA 运行时间，**不包含编码器**。

本地未提交 V4 已加入左右编码器累计计数和左右 RPM，RTL 与 Python 解析有限测试通过，但 V4 完整实现有 setup 违例，因此状态为“未完成”，不能作为集成基线。

此外，用户上板时 V3 经 CP2102 到 RK3588 曾出现持续 timeout，所以当前只能说协议仿真通过，不能说实体串口链路通过。
